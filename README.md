# Real Time Face Detection

## Description
A real-time face detection application built using Python, OpenCV, Streamlit, and streamlit-webrtc.

## Features
- Live webcam access
- Detects human faces in real time
- Displays "Human Face is Detected"
- Displays "Human Face is Not Detected"
- Draws a green rectangle around detected faces

## Technologies Used
- Python
- OpenCV
- Streamlit
- streamlit-webrtc
